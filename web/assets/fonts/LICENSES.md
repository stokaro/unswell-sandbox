# Font licenses

Every font in this directory is licensed under the SIL Open Font License,
Version 1.1. The files are the subsets Google Fonts serves: Latin and Latin
Extended for the text face, Latin plus a few arrow and box-drawing glyphs for
the monospace face.

| Files | Font | Copyright | License text |
| --- | --- | --- | --- |
| `crimson-pro-var-*.woff2` | Crimson Pro (variable, 300-700, upright and italic) | Copyright 2018 The Crimson Pro Project Authors | `OFL-Crimson-Pro.txt` |
| `ibm-plex-mono-*.woff2` | IBM Plex Mono (400, 500, 600) | Copyright © 2017 IBM Corp. with Reserved Font Name "Plex" | `OFL-IBM-Plex.txt` |

Upstream sources: <https://github.com/Fonthausen/CrimsonPro>,
<https://github.com/IBM/plex>.

The two faces are not interchangeable on this page. Crimson Pro carries the
document in Markdown mode, the note messages and the headline; IBM Plex Mono
carries every label, every number, the document in Python mode, and anything
that has to line up in a column.
